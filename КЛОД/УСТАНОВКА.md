# Урок 1. Сценарии — подготовка до урока

Сделай это до урока, займёт 20–30 минут. На уроке сразу запускаем систему на твоих блогерах.

## 1. Что подготовить руками

- [ ] **Claude Code** установлен и работает, подписка Pro или Max.
- [ ] **Google Chrome** установлен.
- [ ] **Отдельный аккаунт Instagram** (не основной). Через него система смотрит ленты блогеров. Войди в него и полистай ленту пару дней, чтобы аккаунт выглядел живым.
- [ ] **Список из 3–5 блогеров**, чьи ролики тебе нравятся и залетают. Можно на английском.
- [ ] **Ключ Groq** (основная расшифровка, бесплатно 8 часов аудио в день, карта не нужна):
  console.groq.com → войти через Google → слева **API Keys** → **Create API Key** → скопировать.
- [ ] **Ключ Gemini** (запасной, бесплатно, карта не нужна):
  aistudio.google.com/api-keys → **Create API key** → скопировать.
- [ ] **Ключ ElevenLabs** (второй запасной, около 4,5 часа в месяц бесплатно):
  elevenlabs.io → слева **Developers** → **API Keys** → создать, включить доступ **Speech to Text**. Ключ показывается один раз, скопируй сразу.
- [ ] **Telegram-бот** для готовых сценариев:
  в Telegram открыть **@BotFather** → `/newbot` → придумать имя → скопировать токен. Затем написать своему боту любое сообщение.

Ключи никому не пересылай и не публикуй. Их вставляешь только в Claude на шаге 2.

Если ты в России: Gemini и ElevenLabs без VPN не работают. Groq и локальная расшифровка работают.

## 2. Промпт для Claude: установить всё

Открой Терминал, набери `claude`, вставь текст ниже целиком.

```
Подготовь мой компьютер к системе поиска сценариев для рилсов. Делай сам, команды запускай сам, у меня спрашивай только ключи и пароль от компьютера.

1. Определи систему: macOS (Apple Silicon или Intel) или Windows.
2. Установи, если нет, и проверь версии:
   - macOS: Homebrew, python3 (3.11+), ffmpeg, yt-dlp (через brew)
   - Windows: python 3.11+, ffmpeg, yt-dlp (через winget)
   - Python-пакеты: patchright, pillow, requests, python-dotenv
   - Расшифровка без интернета: на Mac с Apple Silicon — mlx-whisper, иначе — faster-whisper
3. Создай папку «Сценарии» в домашней папке и внутри файл .env. По очереди попроси у меня ключи и запиши их в .env:
   GROQ_API_KEY, GEMINI_API_KEY, ELEVENLABS_API_KEY, TELEGRAM_BOT_TOKEN.
   Если какого-то ключа у меня нет — пропусти. Значения ключей никогда не выводи на экран.
4. Узнай мой chat_id: запроси getUpdates у Telegram-бота (я уже написал ему сообщение) и допиши TELEGRAM_CHAT_ID в .env.
5. Проверь, что всё работает:
   - скачай звук любого публичного рилса через yt-dlp и расшифруй его через Groq;
   - этот же звук расшифруй локальным whisper;
   - отправь в мой Telegram-бот сообщение «Система готова к уроку 1»;
   - запусти Chrome через patchright и открой instagram.com.
6. В конце выведи таблицу: что установлено ✅, что не получилось ❌ и почему. Ничего лишнего не ставь.
```

## 3. Проверка перед уроком

- [ ] Claude показал таблицу, где всё ✅ (ключи Gemini и ElevenLabs можно пропустить).
- [ ] В Telegram пришло «Система готова к уроку 1».
- [ ] Список блогеров под рукой.

Если что-то ❌ — пришли скриншот таблицы в чат до урока.
